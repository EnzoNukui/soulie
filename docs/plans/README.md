# Planos do projeto Soulie

Esta pasta concentra os documentos que definem produto, experiência, arquitetura e planos de implementação do protótipo.

## Documentos-base

- `DOCUMENTACAO_SOULIE.md`: contexto do produto, requisitos e regras iniciais.
- `PLANO_PROTOTIPO_SITE.md`: experiência, escopo, cenas e etapas do site-protótipo.
- `ARQUITETURA_REACT.md`: arquitetura planejada para React, TypeScript e Vite.

## Planos de tarefas

Toda alteração relevante deve possuir um arquivo próprio nesta pasta, criado a partir de `TEMPLATE.md`.

Use nomes curtos em `kebab-case`, por exemplo:

```text
docs/plans/criar-fundacao-react.md
docs/plans/implementar-onboarding.md
docs/plans/adicionar-cena-missao.md
```

Os documentos-base descrevem a visão. Os planos de tarefa descrevem uma implementação específica e verificável.
