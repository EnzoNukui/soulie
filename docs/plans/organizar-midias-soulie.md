# Organizar mídias adicionais da Soulie

## Objetivo

Organizar as imagens e vídeos fornecidos para uso futuro em reações, notificações e momentos especiais do protótipo.

## Contexto

Os ativos foram enviados antes da reformulação do fluxo posterior às comunidades. Nesta tarefa eles serão apenas catalogados, sem integração na interface.

## Requisitos

- separar imagens de reação, referência de notificação e vídeos;
- normalizar os nomes dos arquivos dentro do projeto;
- preservar os arquivos originais em `Downloads`;
- registrar origem e uso pretendido de cada ativo.

## Fora de escopo

- editar, recortar ou converter as mídias;
- inserir imagens ou vídeos no protótipo;
- alterar feed, missões, notificações ou reinício da jornada;
- definir uma mídia como aprovada sem revisão visual posterior.

## Arquivos ou áreas envolvidas

- `docs/referencias/midias-soulie/reacoes/`;
- `docs/referencias/midias-soulie/notificacoes/`;
- `docs/referencias/midias-soulie/videos/`.

## Plano de implementação

1. conferir os cinco arquivos de origem;
2. criar as categorias de referência;
3. copiar e renomear os arquivos;
4. documentar o catálogo;
5. validar quantidade e integridade básica.

## Critérios de aceite

- [x] os cinco arquivos foram copiados;
- [x] reações, notificação e vídeos estão separados;
- [x] o catálogo registra origem e uso pretendido;
- [x] nenhum arquivo original foi removido ou alterado;
- [x] nenhuma mídia foi integrada ao código nesta etapa.

## Riscos e observações

- vídeos deverão ser avaliados quanto a duração, peso, transparência, corte e movimento reduzido antes do uso;
- a imagem de notificação é uma referência visual, não um layout definitivo nem texto aprovado.
