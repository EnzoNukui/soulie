# Referências visuais — Soul Up e Soulie

Imagens fornecidas pelo usuário em 25 de agosto de 2026 para orientar o planejamento e o desenvolvimento do protótipo da Soulie integrado à interface da Soul Up.

## Arquivos

1. `01-home-carteira-feed.png`
   - Tela principal da Soul Up.
   - Exibe cabeçalho, saldo de 220 pontos, carteira expandida, atalhos financeiros, stories/anúncios, feed e navegação inferior.

2. `02-comunidades.png`
   - Tela principal de comunidades.
   - Exibe busca, criação e acesso às comunidades, ranking Top 10 e navegação inferior.

3. `03-missoes.png`
   - Tela de missões da Soul Up.
   - Exibe Pontos Soul, missões concluídas, filtros, recompensas, ações para começar e progresso.

4. `04-conceito-soulie-no-feed.png`
   - Montagem conceitual fornecida pelo usuário.
   - Representa aproximadamente como a Soulie poderia aparecer dentro do cartão da carteira na tela inicial.
   - Não deve ser tratada como tela oficial ou solução visual definitiva.

## Uso no projeto

Estas imagens devem ser usadas como referências para:

- preservar a identidade visual e os padrões de navegação da Soul Up;
- definir os pontos de entrada da Soulie;
- planejar os fluxos de missões, recorrência, carteira e recompensas;
- comparar futuras propostas com a interface real do aplicativo;
- separar claramente telas existentes de experimentos conceituais.

As imagens originais não devem ser alteradas. Variações, anotações e propostas futuras devem ser salvas em outra pasta.
