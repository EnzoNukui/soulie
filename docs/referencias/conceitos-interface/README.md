# Conceitos de interface da Soulie

Conceitos visuais gerados em 25 de agosto de 2026 para orientar a criação dos wireframes e da interface React.

## Arquivos

- `01-conceito-desktop.png`: painel com landing page, explicação do funcionamento e demonstração/resultados.
- `02-conceito-mobile.png`: fluxo com onboarding, início, recomendação de missão, conclusão e comunidade/impacto.
- `soulie-referencia.png`: imagem original da Soulie fornecida pelo usuário e utilizada como referência visual.
- `PROMPTS.md`: especificações utilizadas na geração dos conceitos.

## Observações

- As imagens definem direção visual, hierarquia e composição aproximada.
- O conceito desktop serve como referência estética, mas sua estrutura institucional foi substituída por uma experiência que começa diretamente com a Soulie.
- A implementação deve priorizar o fluxo mobile apresentado e adaptá-lo para desktop como uma jornada interativa ampliada.
- Textos, números, marcas, ícones e detalhes pequenos não devem ser tratados como conteúdo final.
- A Soul Up aparece somente como contexto visual.
- A interface real deve ser construída com componentes acessíveis e responsivos.
- A aparência da Soulie deve ser adaptada aos estados necessários sem perder sua identidade.
